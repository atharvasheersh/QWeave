# Earlier QWeave research blueprint

This folder preserves the team's pre-implementation planning package. The
three PDFs are in `pdf/`; their editable DOCX sources and the mathematical
foundations LaTeX source are in `source/`. All seven files were copied from
the existing QWeave project blueprint without content changes and their
SHA-256 hashes matched the originals at assembly time.

These documents describe the proposed workflow, architecture/technology
stack, and three-week team execution plan. They predate Diptesh's merged
deterministic core and are **planning references**, not proof that the
PPO/GNN modules, scheduler, or full benchmark have been implemented.
The mathematical-foundations LaTeX source has not been compiled locally.

For current code and evidence, use the repository root README,
`docs/BASELINE_AUDIT.md`, `docs/VALIDATION_SCOPE.md`, and
`docs/EXPERIMENT_PROTOCOL.md`. The active paper draft is in `paper/`.
